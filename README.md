# 🎭 Abartılı Geç Kalma Mazeret Üreticisi

> *Çünkü bazen "trafik vardı" yetmez. Evrenin kendisi seni durdurmalıdır.*

## Bu Ne?

Bu, dünyanın **en ciddi** şekilde yazılmış, **en saçma** geç kalma mazereti üreticisidir.  
Gerçekten çalışır. Gerçekten mazeret üretir. Gerçekten hiçbir işe yaramaz.

### Özellikler

- 📊 3 farklı şiddet seviyesinde mazeret üretir
- ⏳ Dramatik bekleme animasyonu (gerçekten bekler)
- 🎭 Rastgele, absürt, tamamen uydurma ama ikna edici mazeretler
- 🤔 Felsefi derinlik (kedi, asansör, karga, ayakkabı... hepsi var)
- 🚀 %100 Python, %0 mantık

## Nasıl Kullanılır?

```bash
python mazeret_ureticisi.py
```

Çıktı örneği:

```
==================================================
   ABARTILI GEÇ KALMA MAZERET ÜRETİCİSİ v1.0
   (Gerçekten çalışır, gerçekten saçmadır)
==================================================
Mazeret üretmek için evreni sorguluyorum
...

--- Seviye 1 Mazeret ---
Vallahi şu oldu: kedi kapının önünde oturup bana 'bugün gitme' diye baktı ve bu yüzden tam 15 dakika geciktim. Özür dilerim ama bu benim kontrolüm dışında.
```

## Neden Bu Proje?

Çünkü hayat zaten yeterince ciddi.  
Çünkü bazen bir mazerete ihtiyacın olur.  
Çünkü "uyandım" demek artık yeterli değil.

## Katkıda Bulunma

Katkıda bulunmak istiyorsan:
1. Daha absürt olaylar ekle
2. Daha dramatik sonuçlar yaz
3. Kendi mazeretini commit mesajı olarak kullan
